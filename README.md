# Отпускные 2026

Ориентировочный расчёт отпускных за ~30 секунд: грязными, НДФЛ и на руки.

Без аккаунта, без облака, без 1С. Android-приложение для RuStore.

## Что считает

- сумму **грязными** и **на руки**;
- **НДФЛ** 13% / 15% (с учётом дохода с начала года);
- **СДЗ** (средний дневной заработок);
- пол **МРОТ**, если норма отработана полностью, а зарплата ниже;
- **праздники** ст. 112 ТК РФ в периоде отпуска (не входят в оплачиваемые дни);
- опциональный **районный коэффициент**.

История последних 20 расчётов хранится только на устройстве. На результате — баннер Яндекса (можно отключить покупкой без рекламы).

## Это ориентир

Цифры приблизительные. Не юридическая консультация и не замена бухгалтера.

В v1 не учитываем: премии, разбор зарплаты по месяцам, нерезидентов.
